# Снимок корпуса $`D_{t_0}`$

Паспорт снимка корпуса, по которому строится эталонная выборка (ADR-023). Построен командой `make snapshot` (`python -m code.annotation.sample_documents snapshot`).

| Файл | Содержание |
|---|---|
| `meta.json` | $`t_0`$, коллекция Qdrant, число точек, $`N`$ — число документов, SHA-256 отсортированного списка `webpage_id` (строки через `\n`), охват по месяцам, git sha кода |
| `netloc_month_counts.csv` | Число документов снимка по доменам и месяцам публикации (`netloc, month, documents`) |

$`\mathcal{I}`$ — все `webpage_id` коллекции Qdrant (`webpage_id = point_id >> 16`); каждый из них есть в `webmedia.webpages`. Сам список идентификаторов и тексты документов в репозиторий не входят: они хранятся в локальном кэше `data/_cache/` и воспроизводятся при доступе к корпусу ИВ РАН. Совпадение снимка проверяется по `ids_sha256`.
