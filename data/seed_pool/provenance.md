# Происхождение seed pool

Каталог предназначен для стартового пула вопросов (seed pool), из которого после перекладки идентификаторов формируется часть черновиков для разметки эталонной выборки $`G`$. Исходные файлы скопированы без изменений; соответствие `warc_id → webpage_id` построено 2026-10-23 (раздел «Перекладка», [ADR-023](../../docs/decisions.md#adr-023-перекладка-seed-pool-снимок-корпуса-и-отбор-300-позиций)).

## Источник

Два файла из репозитория промышленной системы «Chinese Media Analysis» (`ivran-lab/chinese-media`, ветка `prod`, коммит `5676f9323863cc7c565fa23e63346f0425329ead` от 28 апреля 2025 года — последнее изменение обоих файлов):

| Файл в репозитории промышленной системы | Копия | sha256 |
|---|---|---|
| `production/backend/rag/EN_rag_questions.json` | `EN_rag_questions.json` | `fc2ce159e302dba2f743dee9b75cfaab1f581dbe1dbbc5229dd0132381daad37` |
| `production/backend/rag/RU_rag_questions.json` | `RU_rag_questions.json` | `e588a3207faf43730b68e8d981f97c6fd193d21e3082865021a6dbde19d519b1` |

Каждый файл — JSON-объект вида `{"<вопрос>": "<warc_id>"}`: ключ — текст вопроса, значение — имя файла записи WARC с машинным переводом статьи, по которой вопрос сгенерирован. Файлы EN и RU содержат один и тот же набор вопросов на двух языках (английский и русский переводы одних и тех же черновиков), одинаковый порядок и одинаковые значения `warc_id`.

Формат значения: `trans_txt_<netloc>-<YYYY-MM>.warc_record_<N>.txt`, где `netloc` — домен издания, `YYYY-MM` — месяц выгрузки WARC, `N` — порядковый номер записи внутри архива.

## Почему seed pool не является эталонной выборкой

1. **Нет эталонных ответов.** Записи содержат только вопрос и идентификатор статьи; ни канонического ответа $`A^*_i`$, ни алиасов, ни evidence span нет. Из метрик $`M`$ по этим данным вычислимы только метрики поиска (попал ли документ в выдачу), но не метрики правильности ответа.
2. **Ключ `warc_id` не является стабильным идентификатором.** Имя файла кодирует домен, месяц и порядковый номер записи внутри WARC; в таблице `webmedia.webpages` нет колонки с именем файла, поэтому прямого соответствия `warc_id → webpage_id` нет, и связь приходится восстанавливать косвенно (см. план перекладки ниже). Схема записи $`G`$ требует стабильных ключей `webpage_id`, `urn_uuid`, `uri`.
3. **Неполное покрытие корпусом.** С корпусом и индексом Qdrant сопоставлены 96 из 143 статей (67 %) и 251 из 388 вопросов; статей The News Lens в корпусе нет (раздел «Перекладка»). Для $`G`$ требуется покрытие 1 по построению ($`S^*_i \subset \mathcal{I}`$ и присутствует в Qdrant).
4. **Нет признака инвариантности во времени.** Вопросы не проверялись правилами $`E_1`$–$`E_5`$; по эвристической проверке (ниже) около половины из них — оценочные и прогнозные («как X оценивает…», «какие последствия может иметь…», «как это повлияет на…»), то есть не удовлетворяют $`\mathrm{Inv}(q)`$.
5. **Узкое покрытие.** Три домена и три календарных месяца (2022-06, 2023-04, 2023-05) против требования не менее 12 месяцев охвата; нет источников КНР и Сингапура.
6. **Дефекты формулировок.** Непереведённые фрагменты (английские названия должностей и программ внутри русских вопросов, русские слова внутри английских), составные вопросы из двух подвопросов, отсутствие дат-якорей.

Поэтому seed pool используется только как источник **черновиков**: каждый вопрос проходит ту же процедуру, что и вновь сгенерированные черновики (проверка $`E_1`$–$`E_5`$, добавление даты-якоря, формирование канонического ответа и $`S^*`$, разметка $`R = 3`$ аннотаторами). Ссылка на исходный вопрос сохраняется в поле `provenance.seed_pool_ref` записи $`G`$.

## Эвристическая проверка (базовый эксперимент, ADR-020)

## Перекладка `warc_id → webpage_id / urn_uuid / uri`

Выполнена 2026-10-23 модулем `code/annotation/remap_seed_pool.py` (цель `make seed-remap`). Ключ `warc_id` — имя файла перевода записи WARC; URL и WARC-Record-ID статей сохранились в заголовках исходных файлов промышленной системы вне репозитория (каталог `last_version` проекта): в файлах `og_<stem>` (`old_DB/data_ch_en`, первая строка — URL) и `trans_txt_<stem>` (`data_en`, строки `URL:` и `WARC:`). Поэтому сопоставление точное, без поиска по домену, месяцу и префиксу текста.

1. **Заголовки** → `warc_headers.csv` (`warc_id, netloc, warc_month, record_n, uri, warc_uuid, uri_source, uuid_source`): URL есть у всех 143 статей, WARC-Record-ID — у 97 (RFI и The News Lens); у статей HKET только URL. URL из двух источников совпадают.
2. **Поиск в `webmedia.webpages`**: по `urn_uuid` (WARC-Record-ID); при его отсутствии — по `md5(uri)` с вариантами написания (схема, `www.`, процентное кодирование, завершающий слэш), затем по префиксу: в корпусе к адресу статьи HKET добавлен заголовок (`/article/<номер>/<заголовок>`). Если найдено несколько версий одной статьи, остаётся та, в тексте которой есть заголовок исходного `og_`-файла; при совпадении в нескольких версиях — та, у которой с него начинается заголовок страницы.
3. **Проверка**: заголовок исходного файла найден в тексте каждого сопоставленного документа (`match_score = 1.0`); каждый документ есть в коллекции Qdrant (`in_qdrant`).

| Домен | Статей | Сопоставлено | Метод | Вопросов с документом |
|---|---|---|---|---|
| `www.rfi.fr` | 50 | 50 | `urn_uuid` | 129 |
| `inews.hket.com` | 46 | 46 | `uri_prefix` (39), с выбором версии по заголовку (7) | 122 |
| `www.thenewslens.com` | 47 | 0 | домена нет в корпусе | 0 |
| **Итого** | **143** | **96** | | **251** |

Потери: 47 статей и 137 вопросов The News Lens — в `webmedia.webpages` нет ни одного документа этого домена. Из 251 вопроса с документом 129 не отмечены маркерами правил $`E_1`$, $`E_2`$, $`E_4`$.
