# История версий эталонной выборки

Формат записи — по образцу Keep a Changelog. Каждая выпущенная версия фиксируется тегом git `golden-set-<версия>` и контрольной суммой SHA-256 файла `golden_set.jsonl`. Записи выпущенной версии не изменяются; исправления выходят отдельной версией с перечислением затронутых `id`. Обозначения — как в `docs/problem_statement.md`; правила исключения $`E_1`$–$`E_5`$ — в `docs/annotation_guidelines.md`, раздел 5.
