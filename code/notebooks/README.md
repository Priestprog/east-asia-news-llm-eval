# Ноутбуки

Каталог для Jupyter-ноутбуков, используемых **только для визуализации** результатов из
`results/tables/` и `results/runs/` (графики для `results/figures/`, разведочный анализ
таблиц). Вычисления метрик, статистика и любая логика конвейера живут в модулях
`code/eval/` и `code/annotation/` и вызываются через `Makefile`.

Правила:

- ноутбук читает готовые артефакты (CSV, JSONL) и не пересчитывает метрики;
- перед коммитом очищать вывод ячеек; каталог `.ipynb_checkpoints/` игнорируется;
- итоговые рисунки сохранять в `results/figures/` с именем, совпадающим с именем ноутбука.
